More and more, however, I have been coming to appreciate a minimal approach
to things: why have a web application with PHP, MYSQL and JavaScript driving a
simple website when pure HTML would do just as well - and have a much smaller
attack surface? Granted, I have been influence in this thinking by the likes of
[Bryan Lunduke](http://www.lunduke.com) and [Andrew Roach](http://ajroach42.com).

So I have been gradually learning how to use Hugo and porting my website over to
that as I learn it. And striving to minimize the size of my code and image files
such that this site would work well even on a dial up connection. Given that my
entries will all be written in MarkDown for use in Hugo, I may even look into
creating a Gopher version of this site, because I think that would be kind of
cool.
